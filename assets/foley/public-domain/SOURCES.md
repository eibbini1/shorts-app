# Burger field recordings

- `frying-fries.ogg`: [Frying fries going in and out of oil](https://commons.wikimedia.org/wiki/File:Frying_fries_going_in_and_out_of_oil.ogg), recorded by ezwa, released to the public domain. The burger film uses a short excerpt for griddle sizzle; the source is frying oil, not beef.
- `crunching.ogg`: [Crunching munching grinding](https://commons.wikimedia.org/wiki/File:Crunching_munching_grinding.ogg), recorded by stephan, released to the public domain. The source is crushed pistachio husks; the burger film uses a short excerpt for crispy onion and bun texture.

These are real recordings with different original food sources. The final audio must be listened to and replaced if either cue sounds misleading or out of sync.

## Recorded-action library for new films

- `ambient-kitchen.ogg`: compact Ogg transcode of [Ambient Kitchen Sounds.wav](https://commons.wikimedia.org/wiki/File:Ambient_Kitchen_Sounds.wav), Wilfredor, CC0. Use as room ambience; it is not a cooking-action cue.
- `wood-and-cutlery.ogg`: [Wood and cutlery.ogg](https://commons.wikimedia.org/wiki/File:Wood_and_cutlery.ogg), PDSounds, public domain. It records cutlery placed on a wooden surface; use for cutlery contact, not slicing meat.
- `minced-beef-frying.ogg`: audio extracted from [Kjøttdeig.ogv](https://commons.wikimedia.org/wiki/File:Kj%C3%B8ttdeig.ogv), Kjetil r, public domain. It records minced beef frying, so it is a closer match for a burger griddle than the earlier fries recording.

The `recordings-only` sound policy requires a source URL, license, and recorded action for every declared sample. It blocks any cue without a matching file before GPU work. A passing file check does not establish perceptual accuracy; listen to the full final mix.
