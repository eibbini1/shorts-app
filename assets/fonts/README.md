# Bundled caption fonts

`Poppins-Bold.ttf` — SIL Open Font License 1.1 (https://github.com/itfoundry/poppins).
Bundled so burned-in captions look identical on every machine (the renderer passes
this directory to libass via `fontsdir`). To use another free font (Montserrat
ExtraBold, Anton, Bebas Neue…), drop the .ttf here and set `CAPTION_FONT_NAME`.
