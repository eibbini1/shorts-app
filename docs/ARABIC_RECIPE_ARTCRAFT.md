## What is ready

- `examples/recipes/avocado-egg-salad-ar-60.json` defines six contiguous scenes, the same warm kitchen, exact ingredients, food-action checks, and draft Arabic step captions. The visual and audio paths are an inventory of assets still needed.
- `scripts/arabic_recipe.py` checks scene duration and resolution, footage streams, the 60-second kitchen sound bed, commercial-use status, and captions timed to the reviewed picture. With complete inputs, `--editor artcraft` uses FilmCraft and SoundCraft; `--editor ffmpeg` uses FFmpeg for the whole finishing path. Both run final-file technical QA. They block an existing output. The adapter does not synthesize a voice, generate footage, or silently use optional music. The earlier voiced ArtCraft mode remains available for a future manifest with recorded narration.
- `scripts/arabic_reel_captions.py` creates top-safe, right-to-left 1080×1920 ASS captions with the bundled OFL Cairo font. A 1-second rendered frame was visually checked: Arabic joining, punctuation, and safe placement appeared correct. Draft timing is deliberately rejected for final rendering; the ASMR captions must be verified against the final food actions.
- The FilmCraft exporter can select 30 fps and sizes each portrait source to fit 1080×1920. An existing 10-second two-shot film was re-exported at 1080×1920, 30 fps, 300 frames, 10.005 seconds. Its source motion was 24 fps, so this check proves the export format, not 30-fps motion detail or recipe quality.

## Fastest route to this film

1. Record or license six recipe clips matching the scene times in the JSON and save them at `assets/recipes/avocado-egg-salad-ar/scene-01.mp4` through `scene-06.mp4`. Favor real preparation footage for chopping, pouring, and mixing; do not ask LTX to invent irreversible food actions. Use the same bowl, hands, counter, ingredients and light throughout. Original 1080×1920 30-fps footage avoids upscaling or duplicated frames.
2. Record or license a 60-second kitchen sound bed, `kitchen-bed-60.wav`, with real chopping, bowl, dressing and spoon sounds at their visible actions. The user selected Arabic-captioned ASMR, so this recipe has no voice. Commercial-use sound-effect licenses must be checked. The Mixkit SFX license permits commercial social videos but forbids redistribution of standalone stock files; record each chosen item's source and keep the source WAVs out of Git. This first adapter does not mix a separate music file; it blocks one rather than ignoring it.
3. Review the completed picture and adjust `captionCues` to the actual preparation actions. Then set `captionTimingStatus` to `verified-against-picture` and `soundBed.licenseStatus` to `verified-commercial-use`. These fields record completed reviews; do not flip them before the review.
4. Run `npm run recipe:arabic:check`. It reports all missing or mismatched inputs. When ready, run `python3 scripts/arabic_recipe.py --spec examples/recipes/avocado-egg-salad-ar-60.json --editor ffmpeg --output outputs/avocado-egg-salad-ar-60-ffmpeg.mp4`, or switch to `--editor artcraft` for the FilmCraft/SoundCraft route. Both require a new output path and generate a `.qa.json` final-file technical report.
5. Inspect a contact sheet and all six action transitions, watch the full 60 seconds, and listen to the full mix before release. A technical QA pass alone is not an editorial verdict.

The existing finish uses **PhotoCraft** upstream for optional still preparation, **SoundCraft** for audio mastering, **EffectCraft** for an optional title, and **FilmCraft** for the video timeline and export. This recipe uses real footage where possible, so PhotoCraft need not run. The recipe requests no title, so EffectCraft need not run. FFmpeg remains a low-level utility for transparent captions; FilmCraft is the video editor. ArtCraft cannot manufacture realistic chopping footage or natural kitchen recordings by itself.

No paid API was used. Windows ArtCraft and Arabic font behavior are untested here; the available Mac FilmCraft CLI is the tested platform. The 60-second version still needs the chopping, dressing, mixing and serving motion, plus a 60-second sound bed timed to those actions. The current full recipe manifest correctly blocks rendering while those assets and picture-synced caption checks are missing.
