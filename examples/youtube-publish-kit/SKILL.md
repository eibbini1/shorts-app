# YouTube Publish Kit

Identify the audience and concrete viewer payoff from the supplied material. Use facts from that material. If the user only supplies an idea, write draft copy without claiming the video proves a result.

Return these three items:

1. One title with the main search phrase near the beginning.
2. A two-sentence description that explains the payoff and what the video covers.
3. One thumbnail hook in two to five words that complements the title.

Use plain language. Avoid invented results, rankings, or guarantees. Return drafts only.
